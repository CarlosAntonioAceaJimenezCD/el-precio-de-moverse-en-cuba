## 6. Stack sugerido para el proyecto ICD

1. **Sitios de clasificados** (Revolico, iTENCEL, VentaCuba, Autocubana): Scrapy o Crawlee + Playwright para las partes dinámicas; `curl_cffi` si hay protección TLS; `trafilatura` para limpiar HTML.
2. **Facebook Marketplace/grupos**: Playwright con sesión real + `facebook-gql-scraper` como referencia; `FBScrapeIdeas` para grupos. Muy frágil y con riesgo de bloqueo.
3. **WhatsApp**: solo grupos propios o con consentimiento; `whatsapp-web.js`/Baileys para lectura, nunca para spam masivo.
4. **Telegram**: `Telethon` para canales públicos; `RSSHub` si solo se necesita monitoreo.
5. **Monitoreo continuo**: `changedetection.io` para detectar cambios de precios/stock.

## 7. Advertencia legal

El scraping de Facebook, WhatsApp y Telegram puede violar sus términos de servicio y, según el país, las leyes de protección de datos. Para el proyecto conviene:
- Priorizar APIs oficiales y datos públicos.
- Respetar `robots.txt`, rate limits y derechos de autor.
- No recolectar datos personales sin base legal.
- Usar cuentas propias y consentimiento explícito en grupos de mensajería.
